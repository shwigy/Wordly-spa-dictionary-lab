# Lecturn

A simple single-page dictionary app. Search any word to see its definitions, pronunciation, and synonyms.

## Features

- Search for a word using the search bar
- View definitions grouped by part of speech
- Listen to pronunciation audio
- See synonyms for each meaning
- Friendly error messages for invalid or empty searches

## Built With

- HTML
- CSS
- JavaScript (Fetch API, async/await)
- [Free Dictionary API](https://dictionaryapi.dev/)

## Running Locally

1. Clone this repo
2. Open `index.html` in your browser

No build steps or dependencies required.
